# 종수영어정복 🐳

휴대폰에서 쓰는 영어 학습 웹 앱입니다. 수준은 쉬운 초급~초중급(레벨 2~4 / 10), 여행 · 일상 회화 · 꽃가게 · 물리치료 상황 중심입니다.

## 기능
- 🃏 **단어 카드** — 10개 주제 150단어(꽃가게·물리치료 포함). 모르는 단어는 더 자주 복습(라이트너 방식)
- 💬 **상황별 표현** — 9개 상황 94문장(꽃가게, 물리치료사로서 환자와의 대화 포함). 🔊 듣기, 🐢 천천히 듣기, 🎤 따라 말하기 + 발음 점수
- 📘 **문법** — 30강(기초 1~15, 활용 16~30). 핵심 정리 + 듣기 예문 5개 + 연습 문제 6개(틀리면 이유 설명), 70% 이상이면 완료
- ✏️ **퀴즈** — 뜻 고르기 · 영어 고르기 · 듣고 고르기 · 문장 만들기
- 👩‍🏫 **선생님 대화** — 대본 롤플레이 7개(무료, 꽃가게·물리치료 포함) + Claude API 키를 넣으면 AI 선생님과 자유 대화
- 🔥 **연속 학습일 · 학습 기록** — 최근 7일 활동, 4주 달력, 주제별 진도

학습 기록과 API 키는 모두 휴대폰 브라우저에만 저장되며 서버로 보내지 않습니다
(AI 대화 시 대화 내용만 Anthropic API로 전송).

## 휴대폰에서 열기
GitHub Pages 주소로 접속한 뒤 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.
- 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**
- 안드로이드(크롬): ⋮ 메뉴 → **홈 화면에 추가**

## 구조
빌드 과정 없는 정적 사이트입니다. `index.html`, `css/`, `js/data.js`(단어·표현·롤플레이), `js/grammar1.js`·`js/grammar2.js`(문법 레슨), `js/app.js`(앱 로직).
단어·표현을 추가하려면 `js/data.js`만 고치면 됩니다.
